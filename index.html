About the Conference

MIRAGE 2026 brings together researchers and practitioners to explore deception-based security techniques for modern Java microservice ecosystems. This track focuses on detecting post-compromise attacker activity through gateway-injected honeytokens, offering a novel layer of defense that goes beyond traditional prevention-first security models.

Topics of Interest

Microservice Security
Deception-Based Intrusion Detection
API Gateway Security
Java Spring Boot Cybersecurity
Post-Compromise Detection
